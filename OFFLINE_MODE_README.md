# 🎮 S.T.A.L.K.E.R. Online - OFFLINE MODE PATCH

## 📦 ЧТО ЭТО ТАКОЕ?

Это набор файлов-заглушек (mock-модулей), которые позволяют запускать клиент игры **БЕЗ сервера и без оригинального движка**. Все сетевые вызовы перехватываются и заменяются на безопасные локальные операции.

---

## 🚀 БЫСТРЫЙ СТАРТ

### Шаг 1: Скопируй файлы в папку с игрой

Используй скрипт `deploy.py` (уже создан в корне репозитория):

```bash
python deploy.py
```

Или скопируй вручную из `/workspace/scripts/` в `F:\SO\StalkerOnline\scripts\`:

| Файл | Назначение |
|------|------------|
| `offline_init.py` | Главный инициализатор (копировать ПЕРВЫМ!) |
| `BigWorld.py` | Заглушка игрового движка |
| `ResMgr.py` | Заглушка менеджера ресурсов |
| `Pixie.py` | Заглушка системы частиц |
| `Math.py` | Заглушка математических функций |
| `FX.py` | Заглушка эффектов |
| `GUI.py` | Заглушка интерфейса |
| `client/mocks/__init__.py` | Система сохранений и офлайн-логика |

### Шаг 2: Подключи offline_init

**ВАЖНО:** Это нужно сделать в самом начале загрузки игры!

Найди главный файл запуска (обычно это `main.py`, `client.py` или `EntryPoints.py` в папке `scripts/client/`) и добавь **ПЕРЕД ВСЕМИ ОСТАЛЬНЫМИ ИМПОРТАМИ**:

```python
# В САМОЕ НАЧАЛО ФАЙЛА, перед любыми другими импортами!
try:
    import offline_init
except ImportError:
    pass  # Если запускается в оригинальном движке
```

### Шаг 3: Запусти игру

Запускай свой `.exe` как обычно. В консоли должен появиться лог:

```
============================================================
OFFLINE MODE INITIALIZED
============================================================
Scripts directory: F:\SO\StalkerOnline\scripts
[OK] Mock module found: BigWorld
[OK] Mock module found: ResMgr
[OK] Mock module found: Pixie
...
Offline initialization complete!
You can now start the game.
============================================================
```

## 💾 СИСТЕМА СОХРАНЕНИЙ

Игра автоматически сохраняет прогресс в файл:
```
F:\SO\StalkerOnline\scripts\client\mocks\offline_save.json
```

**Что сохраняется:**
- Имя игрока, уровень, опыт
- Деньги
- Инвентарь
- Выполненные квесты
- Позиция персонажа
- Здоровье и энергия

**Ручное сохранение** (можно вызвать из консоли или кода):
```python
from client.mocks import save_game_state
save_game_state()
```

**Загрузка прогресса:**
```python
from client.mocks import get_game_state
state = get_game_state()
print state['player']['name']
```

## 🐛 ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Ошибка: "ImportError: No module named BigWorld"
**Решение:** Убедись что `BigWorld.py` лежит в папке `F:\SO\StalkerOnline\scripts\`

### Ошибка: "SyntaxError: invalid syntax" при компиляции
**Причина:** Файл содержит синтаксис Python 3, а компилятор Python 2.7
**Решение:** Сообщи мне текст ошибки, я исправлю файл под Python 2

### Игра запускается но зависает на экране загрузки
**Решение:** 
1. Проверь логи консоли
2. Возможно нужен фикс конкретного файла загрузки
3. Сообщи на каком этапе происходит зависание

### Прогресс не сохраняется
**Решение:**
1. Проверь что папка `scripts/client/mocks/` существует
2. Проверь права на запись в эту папку
3. Файл `offline_save.json` должен создаваться автоматически
